# Analyses

Conventions for analysis pages. Project analyses live under `projects/<slug>/wiki/analyses/`, not here.

Use an analysis page for outputs that come from questions, comparisons, synthesis, and exploration:

- comparisons
- timelines
- decision memos
- diagnostics and forensics
- research summaries
- architecture notes

If a chat answer would still be useful later, file it under the owning project and add it to that project's `index.md`.

This shared folder holds only cross-project analyses — ones that would be wrong to file under a single project.
